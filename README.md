# Library Archive

A private searchable media-library starter with sections for Anime, Games, Series, Movies, Music and Other.

## Features
- Login/signup with first-account admin bootstrap
- Category navigation and search
- Trending section based on views, downloads, shares and visits
- Hover cards with quick actions and counters
- SQLite analytics/event tracking
- Admin media entry form
- Responsive dark UI

## Run
```bash
npm install
SESSION_SECRET="use-a-long-random-secret" npm start
```

Only add media resources you own or are authorized to share.
